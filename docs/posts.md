Hello there! I built a website for the community to track and archive the known information surrounding the controversy.

The site includes the following sections:

- **Home** — Overview and stats
- **Timeline** — Chronological archive of events
- **Videos** — Collection of relevant videos
- **Bodycam** — Body camera footage archive
- **Documents** — Legal and official documents
- **Social** — Social media posts and coverage
- **People** — Key individuals involved

The site includes the following features:

- additions from the community to any of the information.
- edit proposals to the existing information (currently only works for the timeline)

Added features after community feedback:

- light and dark mode based on your browser/OS preference.

If anyone would like to help build the website, contributions are welcome via the GitHub repository!
